# Study notes

Use the current learner's checkout. Read [AGENTS.md](../../../AGENTS.md) and [PROFILE.md](../../../PROFILE.md) if not already loaded, then follow the **Query** workflow through the root index and relevant lesson pages. This skill supplies task guidance, not filesystem permissions or authority to publish.

Start from what the learner is trying to understand. Establish the necessary context and prerequisites, explain one useful step or contrast at a time, and adapt to the learner's response. In practice mode, let the learner attempt the question before revealing its answer. Use the existing diagrams when they clarify the point; do not commission new media merely because the question mentions an illustration.

Link the notes behind the answer and distinguish source-supported teaching content from your additional explanation. Apply **Curriculum-aware learning** when deciding depth: use the lesson's recorded scope first and retrieve only relevant requirement passages if needed. A curriculum package is neither a list of everything to teach now nor evidence of the learner's prior knowledge.

An ordinary study conversation does not ingest uploads, edit the wiki or spend on generation. Follow the applicable role and user authorization if the request changes. A read-only tutor can propose a concrete correction or handoff to an authorized writer; it cannot apply the Query workflow's optional writing exception itself. Report uncertain source readings with the context needed to resolve them.
