# Ingest notes

Work in the selected learner's Git checkout. Read [AGENTS.md](../../../AGENTS.md) and [PROFILE.md](../../../PROFILE.md), then follow **Sources**, **Ingest**, **Reading handwritten sources** and the **self-check**. The profile supplies the current standing authorizations; this skill does not broaden them.

Classify the supplied material before writing: class material to learn and reference material have different workflows. Check duplicates, preserve the original source, and inspect the images on which the reading depends, including relevant reference figures and newly resolvable earlier questions. Follow **Visual evidence checks** for conversion metadata, crop limits, order, hashes and discoverable evidence. Do not replace an uncertain reading with a plausible invention.

Use **Curriculum-aware learning** to select relevant depth without loading whole requirements collections or importing another learner's professional package. Write and propagate the source-supported lesson using [note formatting](../../../instructions/note-formatting.md); preserve classroom diagrams and their instructional meaning.

When an authored visual helps, use the repository's [learning-visuals entry](../learning-visuals/SKILL.md). For delegated work, follow the existing [media handoff contract](../../../instructions/media-handoff.md); a request record does not itself start another bot. Carry the original scope, budget and attempt history forward.

Complete the Ingest self-check, indexes, evidence and log before publication under the existing authorization. Report unresolved readings and actual verification limits. Creating a skill, renderer or role does not establish a functioning upload route or grant credentials.
