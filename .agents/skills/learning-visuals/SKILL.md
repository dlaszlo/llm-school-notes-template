# Learning visuals

Use for an authorized note illustration, banner, infographic or precise diagram task. This skill belongs to the whole school-notes Git checkout: resolve the links below relative to this file, and run commands from that checkout. It does not install programs, configure an agent or grant write/spending authority.

Read the target checkout's [AGENTS.md](../../../AGENTS.md) and [PROFILE.md](../../../PROFILE.md) if not already loaded. Establish the learner's task, source evidence, relevant curriculum depth and output scope. Preserve source teaching diagrams and the distinction between lesson content and additions.

* **Select and specify:** use [technical visuals](../../../instructions/technical-visuals.md) for the representation decision, drawing specification, precise/code versus generated image choices, fallbacks and relevant verification. This is an open repertoire, not a subject or diagram whitelist. Existing art or no new image may be the best result.
* **Banner or generated illustration:** read the relevant sections of [media workflows](../../../instructions/media-workflows.md) and [prompt stages](../../../instructions/media-prompts.md), then follow [learning image execution](../../../instructions/learning-image-execution.md). Carry the same authorized request, budget and attempt counters through retries and role handoffs.
* **Authored deterministic visual:** follow [visual tool execution](../../../instructions/install-visual-tools.md#run-a-visual). Check actual availability, create/review the editable source in the checkout, render into a new output directory and inspect the requested artifacts. Use native tooling when the small common runner does not fit; do not change the representation merely to fit an adapter.
* **Finish the authorized scope:** verify the actual visual's teaching claims and readability, not just process success. Follow the existing evidence, source-coverage, image-description and [formatting](../../../instructions/note-formatting.md) rules when embedding it. Record unresolved limits. Publication or a paid call still needs existing authorization.

Read only the mode-specific material needed now. The linked documents remain the policy owners; do not duplicate or rewrite them inside an agent's global skills directory.
